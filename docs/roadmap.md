# Roadmap

Implemented: MV3/WXT/React UI, generic explicit-link discovery, playback restrictions, multi-file selection, native folder downloads, zip.js exports with optional streaming save picker, caption derivatives, manifests, partial failures, retry by selection, unit and installed-extension browser tests, local simulation and documentation.

Next: validate an authorised real session and implement verified tenant adapters for scripted download controls; obtain documented OAuth support where the institution permits it; extract verified chapter/slide synchronization metadata; add language selection and format-specific size estimates; automate streaming sink failure recovery and native save-picker tests; add resumable jobs without persisting signed URLs; improve accessible keyboard progress announcements and institution-specific diagnostics. Network-observed direct media and a strict unencrypted MPEG-TS HLS VOD assembler are implemented in the explicit playback action. Separate audio rendition discovery, direct audio/caption files and loaded browser cue snapshots are implemented. DASH, fragmented MP4, segmented WebVTT timestamp maps, discontinuities, separate audio muxing and MP4 remuxing remain unsupported; consider them only with export authorisation and verified non-DRM contracts.
