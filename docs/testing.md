# Testing

`npm run test:all` runs strict typechecking, Vitest, a production WXT build and Playwright Chromium. Install Chromium first with `npx playwright install chromium`. Browser tests need permission to launch Chromium and listen on localhost port 4173. They use a persistent context with the built extension loaded and discover its service worker ID; no browser security is disabled.

Vitest covers URL recognition, metadata, resource classification and restrictions, unsafe links, caption timing, malformed captions, filename handling, redaction, selection, successful output and HTTP failure. Playwright covers nine fictional lecture scenarios, installed content-script discovery, actual ZIP downloads and manifests, transcript bytes, restricted/malformed resources, partial failures and native folder file bytes. Test fixtures are intentionally fictional. Successful ZIP tests force the bounded Blob fallback to automate download inspection; native save-picker streaming requires a manual browser check. Traces and screenshots are retained on failure; scenario screenshots are also generated. Native picker interactions and real tenant schemas are not covered by these automated assertions.

## Authorised real-session procedure

1. Load the unpacked production build and open a recording whose owner explicitly permits exports. Keep credentials entirely in the normal Panopto browser flow.
2. Verify title/ID and enabled download affordances; compare the extension list to actual owner-enabled resources. If no standard links exist, record this as an unsupported DOM adapter, not a missing permission to work around.
3. Export one small caption file and check original timings, language, text, SRT and JSON. Compare with the viewer. Do not send signed source URLs or cookies to issue trackers.
4. Export selected media to Folder and streaming ZIP; play the results and compare stream relationships. Test revoked permissions, sign-in expiry, network interruption, duplicate names, and a file larger than available RAM. Inspect partial manifests before accepting an archive.
5. Check Moodle embedding and custom domain grant/revoke. Close the export manager mid-job; rediscover to retry. Inspect browser download history as needed locally.
6. Supply anonymised contracts and policy evidence for future adapters. Never publish university recordings, tokens or private URLs as fixtures.
